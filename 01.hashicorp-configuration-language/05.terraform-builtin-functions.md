# Built-in functions

Terraform has no user-defined functions. The standard library is documented at [language/functions](https://developer.hashicorp.com/terraform/language/functions). Provider-defined functions (Terraform 1.8+) look like `provider::aws::arn_parse("arn:aws:...")`.

Try expressions in `terraform console`.

## Files and encoding

| Function | Example |
|---|---|
| `file(path)` | `file("${path.module}/policy.json")` |
| `templatefile(path, vars)` | `templatefile("${path.module}/ud.sh.tftpl", { env = var.env })` |
| `jsonencode` / `jsondecode` | Build or parse JSON |
| `yamlencode` / `yamldecode` | Same for YAML |
| `base64encode` / `base64decode` | User data, kubeconfig |

`path.module` is the directory of the file that is evaluating. `path.root` is the root module. `path.cwd` is the process working directory. In modules, prefer `path.module` so the file still resolves after the module moves.

## Collections

| Function | Use |
|---|---|
| `length`, `keys`, `values`, `contains` | Size and membership |
| `merge(a, b)` | Later maps win on duplicate keys. Standard tag pattern. |
| `concat`, `flatten`, `distinct`, `compact`, `sort`, `slice` | Lists |
| `toset`, `tolist`, `tomap`, `values` | Convert. `set` → `tolist` before indexing. |
| `lookup(map, key, default)` | Key may be absent |
| `zipmap(keys, values)` | Build a map |
| `one(list)` | Assert the list has exactly one element |

## Strings and numbers

| Function | Use |
|---|---|
| `format`, `join`, `split`, `replace`, `regex` | Assemble names and parse IDs |
| `lower`, `upper`, `trim`, `trimspace` | Normalize |
| `tostring`, `tonumber` | Coerce |
| `cidrsubnet(prefix, newbits, netnum)` | `cidrsubnet("10.0.0.0/16", 8, 1)` → `10.0.1.0/24` |
| `cidrhost(prefix, hostnum)` | An address inside a CIDR |
| `min`, `max`, `abs`, `ceil`, `floor` | Numbers |

## Guard rails

| Function | Use |
|---|---|
| `try(a, b, c)` | First value that does not error |
| `can(expr)` | `true` when `expr` would succeed. Common in `validation` |
| `coalesce(a, b, c)` | First non-null, non-empty string |
| `alltrue` / `anytrue` | Reduce a list of bools |

```hcl
validation {
  condition     = can(cidrhost(var.vpc_cidr, 0))
  error_message = "vpc_cidr must be a valid CIDR."
}
```

## Time

`plantimestamp()` is stable for the whole plan. `timestamp()` changes on every refresh, so using it in a resource argument forces a perpetual diff. Prefer `plantimestamp()` when a value must be known at plan time and stay fixed through apply.
