# Conditions

The conditional operator picks one of two values. Both branches must have the same type.

```hcl
instance_type = var.environment == "prod" ? "t3.medium" : "t3.micro"
```

`condition ? true_value : false_value`. Terraform evaluates both branches, so neither branch may reference a value that only exists in that branch. Use `try()` when a missing key or attribute is the point: [`06.expressions.md`](06.expressions.md).

## Create the resource or skip it

```hcl
resource "aws_instance" "test" {
  count         = var.environment == "test" ? 1 : 0
  ami           = data.aws_ami.al2023.id
  instance_type = "t3.micro"
}
```

Read a `count` of 0 or 1 with `one(aws_instance.test[*].id)` or `aws_instance.test[0]` when you know it exists.

For several named copies, prefer `for_each` over a map and omit the key. A chain of `count = var.is_test ? 1 : 0` resources gets hard to read once a third environment appears. Environment differences belong in tfvars: [`04/06`](../04.advanced-terraform/06.multi-environment-strategies.md).

## Filter inside a for expression

```hcl
public_subnet_ids = [
  for k, s in aws_subnet.this : s.id
  if var.subnets[k].public
]
```

## String directives

```hcl
template = <<-EOT
  %{ if var.environment == "prod" ~}
  log_level=info
  %{ else ~}
  log_level=debug
  %{ endif ~}
EOT
```

`~` trims the adjacent newline. For anything longer than a few lines, use `templatefile()`.
