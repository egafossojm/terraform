# Conditional expressions

- Allow to avoid duplicating one configuration and commenting one part in specific case.

Ex: Change instance type acciding to the environment (Test/Prod)
- If Test deploy t2.micro instance
- If Prod deploy t2.medium instance instead.

```tf
variable "is_test" {
  type = bool
  default = true 
}

resource "aws_instance" "test-server" {
  ami = data.aws_ami.amazon_linux_2023.image_id
  instance_type = "t2.micro"
  count = var.is_test == true ? 1 : 0  
}

resource "aws_instance" "prod-server" {
  ami = data.aws_ami.amazon_linux_2023.image_id
  instance_type = "t2.medium"
  count = var.is_test == false ? 1 : 0  
}
```
- You just need to change the `is_test` variable value when switching between environments.
