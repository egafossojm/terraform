# Types

Set `type` on every variable. Errors then name the bad value instead of failing deep in a resource.

```hcl
variable "web_port" {
  type    = number
  default = 80
}
```

Write `type = string`, not `type = "string"`.

## Primitive

| Type | Literal | Notes |
|---|---|---|
| `string` | `"ca-central-1"` | Quotes required |
| `number` | `80`, `1.5` | No quotes |
| `bool` | `true`, `false` | No quotes |

## Collection (one element type)

| Type | Shape | Read |
|---|---|---|
| `list(string)` | Ordered, duplicates allowed | `var.azs[0]` |
| `set(string)` | Unique, unordered | `toset(...)`, then iterate. No stable index. |
| `map(string)` | Keys to one value type | `var.amis[var.region]` |

```hcl
variable "azs" {
  type    = list(string)
  default = ["ca-central-1a", "ca-central-1b"]
}

variable "amis" {
  type = map(string)
  default = {
    "ca-central-1" = "ami-0123456789abcdef0"
  }
}
```

`type = map` or `type = list` with no element type is legacy. Write `map(string)` and `list(string)`.

## Structural (mixed types)

| Type | Shape |
|---|---|
| `tuple([string, number, bool])` | Fixed length, position matters |
| `object({ name = string, ports = list(number) })` | Named attributes |

```hcl
variable "egress" {
  type = object({
    from_port = number
    to_port   = number
    protocol  = string
    cidr      = list(string)
  })
  default = {
    from_port = 0
    to_port   = 0
    protocol  = "-1"
    cidr      = ["0.0.0.0/0"]
  }
}
```

Access with `var.egress.protocol` or `var.egress["protocol"]`.

`optional(bool, false)` marks an object attribute that callers may omit (Terraform 1.3+). `nullable = false` rejects `null`.

## `any`

`any` lets Terraform infer the type from the value. Fine for a tiny local script. Module inputs should name the type so callers fail early.

Prefer a `map(object({...}))` over several parallel lists. One key then carries cidr, AZ, and a public flag together. See [`04/08`](../04.advanced-terraform/08.stable-addresses-count-and-for-each.md).
