# Locals

Locals are named values computed inside the module. Callers cannot set them. They exist to remove repetition.

```hcl
locals {
  name_prefix = "${var.environment}-${var.name}"
  common_tags = {
    Environment = var.environment
    Project     = var.project_name
    ManagedBy   = "terraform"
  }
}

resource "aws_vpc" "main" {
  cidr_block = var.vpc_cidr
  tags = merge(local.common_tags, {
    Name = "${local.name_prefix}-vpc"
  })
}
```

Reference them as `local.name_prefix` (singular), even though the block is `locals`.

| | Variable | Local |
|---|---|---|
| Who sets it | Caller, tfvars, CLI, `TF_VAR_` | The module |
| May reference `var`, resources, other locals | In `validation` (1.9+). Not in `default`. | Yes |
| Visible outside the module | As an input | Only if you also output it |
| Typical use | Region, CIDR, instance size | Name prefix, merged tags, filtered lists |

A literal that never changes (`"payments"`) can be a local. A value that differs per environment is a variable, even when it has a default.

Locals can depend on other locals. Terraform orders them. A cycle (`local.a` uses `local.b` and the reverse) is an error.
