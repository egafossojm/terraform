# count, for_each, dynamic

A resource block declares one object until you set `count` or `for_each`.

## count

`count` uses a number. Addresses are indexes: `aws_instance.web[0]`.

```hcl
resource "aws_instance" "web" {
  count         = 3
  ami           = data.aws_ami.al2023.id
  instance_type = "t3.micro"
  tags          = { Name = "web-${count.index}" }
}

output "public_ips" {
  value = aws_instance.web[*].public_ip
}
```

```hcl
resource "aws_iam_user" "this" {
  count = length(var.iam_users)
  name  = var.iam_users[count.index]
}
```

Indexes follow list order. Inserting or deleting an item in the middle shifts every later index, and Terraform plans replacements. `count` fits two cases: a resource that exists or not (`count = var.enabled ? 1 : 0`), and a list that never changes order.

## for_each

`for_each` uses a map or a set of strings. Addresses are keys: `aws_iam_user.this["dev"]`. Removing one key destroys only that instance.

```hcl
resource "aws_iam_user" "this" {
  for_each = toset(var.iam_users) # set(string); list needs toset()
  name     = each.key
}
```

Inside the block, `each.key` and `each.value` are the current item. For a set they are equal. For a map, `each.value` is the object.

```hcl
resource "aws_subnet" "this" {
  for_each          = var.subnets # map(object({ cidr = string, az = string }))
  vpc_id            = aws_vpc.main.id
  cidr_block        = each.value.cidr
  availability_zone = each.value.az
  tags              = { Name = each.key }
}
```

Modules accept `for_each` the same way: `module.app["checkout"]`.

Converting `count` to `for_each` needs a `moved` block per instance, or Terraform treats the new keys as new objects.

## dynamic blocks

`dynamic` generates nested blocks (security group rules, inline policies). The iterator name defaults to the block name.

```hcl
dynamic "ingress" {
  for_each = var.ingress_ports
  content {
    from_port   = ingress.value
    to_port     = ingress.value
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }
}
```

Use this when the nested block itself varies. Ordinary arguments stay as arguments.
