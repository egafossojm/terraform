# Expressions

## Interpolation

```hcl
name = "web-${var.environment}"
```

`"$${var.x}"` emits a literal `${var.x}`.

## for

`for` builds a value. It does not create infrastructure. `for_each` and `count` do.

```hcl
locals {
  upper_names = [for name in var.names : upper(name)]

  public_ids = [
    for k, subnet in aws_subnet.this : subnet.id
    if var.subnets[k].public
  ]

  cidrs = { for k, subnet in var.subnets : k => subnet.cidr }
}
```

List form uses `[ ]`. Map form uses `{ }` and `key => value`.

## Splat

`[*]` projects one attribute from a list (a `count` resource, or a list attribute).

```hcl
aws_instance.web[*].id
aws_instance.web[*].tags.Name
```

Splat on an empty list is an empty list, which is why it is safer than `[0]` when `count` may be 0.

## try and can

```hcl
name = try(var.tags["Name"], var.name, "unnamed")

# validation: the expression parses
condition = can(regex("^[a-z0-9-]+$", var.name))
```

`try` swallows errors. Use it at the edge of optional data, not to hide a typo in a required attribute.

## Operators

| Kind | Operators |
|---|---|
| Arithmetic | `+ - * / %` |
| Comparison | `== != < > <= >=` |
| Logic | `&&`, `||`, `!` |
| Conditional | `cond ? a : b` |

Logic operators do not short-circuit. `var.a && var.b[0]` still evaluates `var.b[0]` when `var.a` is false. Guard with `try`, or structure the data so the index exists.

## Directives in strings

```hcl
yaml = <<-EOT
  users:
  %{ for user in var.users ~}
    - ${user}
  %{ endfor ~}
EOT
```

`<<-EOT` strips the smallest leading indent. `<<EOT` does not. A template longer than a few lines belongs in a `.tftpl` file and `templatefile()`.
