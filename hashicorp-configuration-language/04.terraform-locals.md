# Locals

- Terraform locals (`locals`) are named values that you can refer to in your configuration.
- locals will help to simplify the configuration by `avoiding repetition` and writing more readable code by using `meaningful names` instead of hard coding values.

>[!NOTE]
>
> compared to variable,
> - **locals do not change values during a Terraform run.**
> - **locals are not submitted by users but calculated inside the configuration.**

- Locals are available only in the `current module`: The are scoped locally

EX1: Tagging all our configuration with common tags

```tf
locals {
  common-tags = {
    environment = "Development"
    Version     = 1.10
    project     = "${var.project_name} project"
  }
}

resource "aws_vpc" "vpc1" {
  cidr_block         = var.vpc_cidr_block
  enable_dns_support = var.enable_dns

  tags = merge(
    local.common-tags,
    {
      Name = "Production ${var.main_vpc_name}"
    }
  )
}

resource "aws_subnet" "web" {
  vpc_id            = aws_vpc.vpc1.id
  cidr_block        = var.web_subnet
  availability_zone = var.azs[0]

  tags = merge(
    local.common-tags,
    {
      Name = "web-subnet"
    }
  )
}

resource "aws_internet_gateway" "vpc1_igw" {
  vpc_id = aws_vpc.vpc1.id
  tags = merge(
    local.common-tags,
    {
      "Name" = "${var.main_vpc_name} IGW"
    }
  )
}

resource "aws_default_route_table" "vpc1_default-rt" {
  default_route_table_id = aws_vpc.vpc1.default_route_table_id
  route {
    cidr_block = "0.0.0.0/0"
    gateway_id = aws_internet_gateway.vpc1_igw.id
  }
  tags = merge(
    local.common-tags,
    {
      "Name" = "${var.main_vpc_name} defaut RT "
    }
  )
}

resource "aws_default_security_group" "default_sg" {
  vpc_id = aws_vpc.vpc1.id

  dynamic "ingress" {
    for_each = var.ingress_ports
    content {
      from_port   = ingress.value
      to_port     = ingress.value
      protocol    = "tcp"
      cidr_blocks = ["0.0.0.0/0"]
    }
  }

  dynamic "ingress" {
    for_each = var.ingress_ports
    content {
      from_port   = ingress.value
      to_port     = ingress.value
      protocol    = "tcp"
      cidr_blocks = ["0.0.0.0/0"]
    }
  }

  egress {
    from_port   = var.egress_default_sp_params["from_port"]
    to_port     = var.egress_default_sp_params["to_port"]
    protocol    = var.egress_default_sp_params["protocol"]
    cidr_blocks = var.egress_default_sp_params["cidr"]
  }

  tags = merge(
    local.common-tags,
    {
      "Name" = "${var.main_vpc_name} Default SG"
    }
  )
}

## Locals vs Variables

- Variable = Input (Static data), Locals = processing(combine data)
- Variable values cannot have interpolation, Locals can
```tf
# Working !!!
locals {
  common-tags = {
    environment = "Development"
    Version     = 1.10
    project     = "${var.project_name} project"
  }
}

# Failing
variable "my_variable" {
    type = map(string)
    default = {
    environment = "Development"
    Version     = 1.10
    project     = "${var.project_name} project" # fails because of interpolation
  }
}
```
- Locals are scoped in the module only
- With Locals you can merge tags.


## Conclusion
- ScenarioUse a variableUse a localValue must be changed by the user (e.g., Region) -> Variable
- Value depends on another variable or resource -> local
- Value is an internal constant (e.g., "ProjectName") -> local
- You want to combine default tags and custom tags -> local
