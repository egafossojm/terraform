# Data sources

A **resource** manages an object Terraform created. A **data source** reads an object that already exists.

```hcl
data "aws_ami" "al2023" {
  most_recent = true
  owners      = ["amazon"]

  filter {
    name   = "name"
    values = ["al2023-ami-2023*-x86_64"]
  }
}

resource "aws_instance" "web" {
  ami           = data.aws_ami.al2023.id
  instance_type = "t3.micro"
}
```

Address: `data.<type>.<name>.<attribute>`. Same data source in state shows `mode = "data"`.

| Use a data source | Use a variable or SSM instead |
|---|---|
| AMIs, AZs, caller identity, a VPC you look up by tag | IDs your own stack should own |
| A secret **read** (see the secrets note for ephemeral reads) | A huge "list the whole account" query |

Data sources run during plan, so a slow or broad one makes every plan slow. Filter them.

`depends_on` is for the rare case where the dependency is invisible to the graph (the API is not ready, but you never read an attribute). Prefer reading an attribute: that both orders the graph and passes the value.
