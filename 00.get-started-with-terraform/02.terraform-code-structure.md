# Code structure

A **module** is a directory of `.tf` files. The directory you `init` / `plan` / `apply` is the **root module**. Modules it calls are **child modules**.

Terraform concatenates every `.tf` file in that directory into one configuration. Filenames are a convention.

| File | Contents |
|---|---|
| `versions.tf` | `required_version`, `required_providers` |
| `backend.tf` | `backend` or `cloud` |
| `providers.tf` | `provider` blocks |
| `main.tf` | resources, data sources, module calls |
| `variables.tf` | inputs |
| `outputs.tf` | outputs |
| `locals.tf` | locals, once they grow |
| `terraform.tfvars` | non-secret values for this root |
| `.terraform.lock.hcl` | exact provider versions — commit it |

## Blocks

```hcl
resource "aws_vpc" "main" {    # block type, then labels
  cidr_block = "10.0.0.0/16"   # argument
  tags       = { Name = "main" }
}
```

| Labels | Blocks |
|---|---|
| 0 | `terraform`, `locals` |
| 1 | `provider`, `variable`, `output`, `module`, `moved`, `import`, `removed`, `check` |
| 2 | `resource`, `data`, `ephemeral` (`type` and `name`) |

Comments: `#`, `//`, `/* */`.

## Git

| Commit | Keep local |
|---|---|
| `*.tf`, `.terraform.lock.hcl`, non-secret `*.tfvars` | `.terraform/` |
| examples, README | `*.tfstate`, `*.tfstate.*`, `*.tfplan`, credentials |

The `backend` and `terraform` blocks accept literals only. `var.*` is not available there.
