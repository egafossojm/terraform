# Providers

A **provider** is the plugin that talks to an API (AWS, Azure, Kubernetes, GitHub). Terraform Core builds the graph. Providers create, read, update, and delete objects.

Browse them on the [Terraform Registry](https://registry.terraform.io/browse/providers).

| Tier | Who publishes |
|---|---|
| Official | HashiCorp |
| Partner | A vendor, verified by HashiCorp |
| Community | Everyone else |

## Declare and configure

`required_providers` belongs in the root, and in each child module that wants a clear compatibility range. The `provider` block belongs in the **root**.

```hcl
terraform {
  required_version = ">= 1.11.0, < 2.0.0"

  required_providers {
    aws = {
      source  = "hashicorp/aws" # registry address
      version = "~> 6.0"        # >= 6.0, < 7.0
    }
  }
}

provider "aws" { # "aws" is the local name, and it matches the key above
  region = "ca-central-1"
}
```

`terraform init` downloads the plugin into `.terraform/` and records the exact build in `.terraform.lock.hcl`.

## A second configuration

An alias is a second client (another region or account). Resources opt in with `provider = aws.use1`.

```hcl
provider "aws" {
  alias  = "use1"
  region = "us-east-1"
}
```
