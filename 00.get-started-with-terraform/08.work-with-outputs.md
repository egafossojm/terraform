# Outputs

Outputs are the return values of a module. Root outputs print after `apply` and are stored in state. `plan` does not print them.

```hcl
output "vpc_id" {
  description = "ID of the VPC"
  value       = aws_vpc.main.id
}

output "db_password" {
  value     = var.db_password
  sensitive = true
}
```

Child outputs are how the parent reads a module: `module.vpc.vpc_id`.

## CLI

```bash
terraform output                 # all root outputs
terraform output -raw vpc_id     # bare string, for scripts
terraform output -json > out.json
```

`sensitive = true` redacts the value in the normal output list. `terraform output -raw db_password` and `terraform output -json` still show it. Sensitive values are still written to state.

Declare outputs in `outputs.tf`. Export IDs, ARNs, and names that callers need. Exporting a whole resource object ties callers to every attribute.
