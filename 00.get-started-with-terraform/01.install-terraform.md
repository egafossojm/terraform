# Install Terraform

Pin one CLI version for your laptop and for CI. These notes use **1.16**.

## Linux (HashiCorp RPM repo)

RHEL, CentOS, Fedora, Amazon Linux. This writes the repo file directly, so it works on both dnf 4 and dnf 5:

```bash
wget -O- https://rpm.releases.hashicorp.com/RHEL/hashicorp.repo | sudo tee /etc/yum.repos.d/hashicorp.repo
sudo dnf install -y terraform
terraform version
```

On dnf 5 the equivalent of the old `--add-repo` flag is:

```bash
sudo dnf config-manager addrepo --from-repofile=https://rpm.releases.hashicorp.com/RHEL/hashicorp.repo
```

Debian and Ubuntu use the HashiCorp apt repo. macOS: `brew install hashicorp/tap/terraform`.

## Pin the binary

[tenv](https://github.com/tofuutils/tenv) (or tfenv) reads `.terraform-version`:

```bash
tenv terraform install 1.16.1
tenv terraform use 1.16.1
```

Put the same version in CI (`hashicorp/setup-terraform` with `terraform_version`).

## Shell and editor

```bash
terraform -install-autocomplete
```

Install the HashiCorp **Terraform** extension in VS Code or Cursor. It highlights HCL and surfaces registry docs.

> [!TIP]
> `terraform version` on your laptop and in CI should print the same number. A floating "latest" install is how two plans disagree.
