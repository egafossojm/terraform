# Testing, policy, and cost

Huge infra needs checks **before** apply. `terraform plan` is necessary but not enough.

### 1. Static checks (every PR)

```bash
$ terraform fmt -check -recursive
$ terraform validate
$ tflint
$ trivy config .
# or
$ checkov -d .
```

| Tool | What it catches |
|---|---|
| `fmt` | Style drift |
| `validate` | Invalid HCL / missing required args |
| `tflint` | Provider-specific smells (invalid instance type, unused vars) |
| `tfsec` / `trivy` / Checkov | Security (public S3, open SG) |

### 2. `terraform test` (module unit tests)

Terraform can run `.tftest.hcl` files against a module.

```hcl
# modules/vpc/tests/basic.tftest.hcl
variables {
  cidr_block = "10.20.0.0/16"
}

run "plan_has_vpc" {
  command = plan

  assert {
    condition     = aws_vpc.this.cidr_block == "10.20.0.0/16"
    error_message = "VPC CIDR was not passed through."
  }
}
```

```bash
$ cd modules/vpc
$ terraform test
```

- Fast tests use `command = plan` (no real AWS)
- Slower tests `command = apply` in a **throwaway** account

### 3. Integration tests

Tools like **Terratest** (Go) apply a real example, hit an HTTP URL or describe a SG, then destroy.

Use for pattern modules you ship to many teams. Do **not** "test" by applying prod.

### 4. Policy as code

Guardrails the platform team owns:

- No public S3
- Required tags (`Owner`, `Environment`, `DataClass`)
- Allowed instance families
- No `0.0.0.0/0` on SSH

Engines:

- OPA / Conftest on the plan JSON
- Sentinel (HCP Terraform)
- Checkov / tfsec in CI

```bash
$ terraform plan -out=tfplan
$ terraform show -json tfplan > plan.json
$ conftest test plan.json
```

### 5. Cost on the PR

**Infracost** (and similar) comments a monthly delta:

```bash
$ infracost diff --path=tfplan
```

A module bump that adds NAT gateways in three AZs should be visible **before** merge.

### 6. Required tags (cheap governance)

```tf
provider "aws" {
  region = var.aws_region

  default_tags {
    tags = {
      ManagedBy   = "terraform"
      Environment = var.environment
      Owner       = var.owner
    }
  }
}
```

Combine with a policy: apply fails if `Owner` is missing.

### 7. Layered strategy

```text
fmt / validate / tflint     → every PR
policy + cost               → every PR on live/
terraform test              → every PR on a module repo
Terratest / apply in dev    → before tagging vX.Y.Z
human review of destroys    → every prod apply
```
