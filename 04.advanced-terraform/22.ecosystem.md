# Ecosystem

Same language, several products. Know which name you mean.

| Name | What it is |
|---|---|
| Terraform CLI | The binary (`terraform`). Current release in these notes: **1.16**. License: BSL since 1.6. |
| OpenTofu | Linux Foundation fork from Terraform 1.5.x, MPL. HCL, providers, and the workflow match for interview purposes. State encryption is an OpenTofu extra. |
| HCP Terraform | Hosted runs, state, RBAC, policy. Formerly Terraform Cloud. `cloud` block. |
| Terraform Enterprise | Self-hosted HCP Terraform. |
| Providers | Plugins (`hashicorp/aws`). Versioned apart from the CLI. This repo uses AWS provider 6.x. |

## Tools people add around the CLI

| Tool | Adds |
|---|---|
| tenv / tfenv | Pin the CLI with `.terraform-version` |
| tflint, trivy, Checkov | Lint and security checks in CI |
| OPA / Conftest, Sentinel | Policy on the plan JSON (Sentinel is the HCP Terraform engine) |
| Infracost | Cost diff on the pull request |
| Atlantis, Spacelift, Env0 | Plan and apply from pull requests |
| Terragrunt, Terramate, Atmos | Generate root boilerplate and order many states |
| Terratest | Apply a real example from Go tests |

Pick modules for resource reuse, an orchestrator when root files are the pain, and HCP Terraform or Atlantis when people and audit are the pain. One of each is enough.

Feature markers worth dating in an interview:

| Version | Feature |
|---|---|
| 1.5 | `import` and `check` blocks |
| 1.6 | `terraform test` |
| 1.7 | `removed` blocks |
| 1.8 | Provider-defined functions |
| 1.9 | Validation may reference other variables |
| 1.10 | Ephemeral variables, outputs, and resources |
| 1.11 | Write-only arguments (`password_wo`) |
| 1.16 | `import` blocks allowed inside modules; `store` block on `terraform_data` |
